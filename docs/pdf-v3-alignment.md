# PDF v3.0 对照与验收

《团队 AI 自动化视频生成工作流》PDF v3.0 是目标规范。以下按 PDF 页码标注代码落地，不用当前仓库反改 PDF，也不把可选接口写成已验收。

| PDF | 已接入 | 仍需补齐或实测 |
| --- | --- | --- |
| 01、08 首次配置 | 独立目录、SQLite 初始化、FFmpeg 检测、账号配置模板、YouTube 桌面 OAuth 入口 | 成员确认真实设备、样片、声线、同步目录及权限；自动安装 Ollama/系统依赖不是当前入口职责 |
| 02、03 采集与取题 | YouTube 官方关键词、频道上传列表与 mostPopular；授权元数据导入；平台+ID 去重、快照、带权打分及置信度 | 官方 Key 和 API 联网待实测；AI 负责提交审核后的评分输入。其他平台只在获准时采集，否则导入；RSS、自动更新关键词与相似题检测待接入 |
| 04 个人库 | SQLite 非同步目录、四份 Excel 原子导出，支持 Drive for desktop 已登录的同步目录 | Google Drive 实际同步待成员本机确认；无内置 Drive API |
| 05 至 07 创作与制作 | 已查证素材配合 Ollama 结构化写稿，或导入审核文稿；Kokoro 可选、现有 Edge TTS 或外部实际配音；图文轻动效、MP4、SRT、原始音频和结构时间轴 | Ollama、Kokoro 及 Edge TTS 实际服务待目标设备验证；历史模块入口先登记为未接入，待合法资源、通用适配和样片验收后才启用；未内置通用混音或独立评审模型 |
| 09 定时、发布及回流 | 按 IANA 时区和前序成功状态执行本机作业；人工审批锁定产物；手动回填、官方 YouTube 私享上传及处理查询后排期；报表指标可导入 | 各 OS 定时器实际装机、OAuth 私享测试及真实排期未实测；无自动公开测试、不支持 C 无人值守或自动采集留存/CTR |
| 10、11 质量和统一命令 | 技术门槛、审核量表、产物哈希、防重复提交、JSON 结果、基础模块注册表 | 三次单账号、十次跨成员端到端、两种可执行 AI、适用语言/画幅及权限恢复均未验收 |

验证：仓库英文三场景输入，用离线合成英文配音及测得的真实句级时间走统一入口，输出 23.2 秒、1280×720 H.264/AAC 视频、SRT、封面、时间轴、配音和 QC 日报。完整解码及技术门槛通过；视频未发布。故障用例覆盖采集失败中止、同日防重、错频道、未审核及成片改动后阻止发布。详见 `tests/`。
