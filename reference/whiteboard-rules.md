# 白板手写视频长期规则

（白板模块专用。用户 2026-11-25 立：指出的问题不是只改当处，而是整条视频、以后每次都适用的规则；改完一处，必须全片复查同类问题。）

1. 每个元素配一段真实配音片段，时长按词数走，最短不低于 1.2 秒，渲染后打时序表自查。
2. 标注（圆圈、下划线、箭头、勾）必须真正圈住或指向实物，位置按实物尺寸算。
3. 版式每页换骨架，不是只换左右位置：居中大字、分栏、横带、通栏、竖排、九宫格、三卡横排等轮换；图文平衡，加彩色卡片 / 底色。
4. 一个元素只画一件事；完整图形先画完，再写旁边的字。
5. 混合动效：关键文字数字手写；卡片弹出、数字线 / 箭头滑入、副行淡入。
6. 音效只在图形绘制或关键数字书写时响，不随机；音量低于配音。
7. 图标必须一眼能认出、真对应内容（不是装饰硬贴）；每个图形自带细节和标签，不画空形状——轮子要有辐条＋轮毂＋转动箭头，房子要有烟囱窗户门，钟要有刻度指针，日历要有月份头；位置一律按文字实测宽度（PIL textlength）算进空位，绝不估算、绝不压字。
8. 自查必须看每段最后一帧（不是中间帧），逐页检查重合、溢出、遮挡。
9. 音效混音不用 ffmpeg amix 多路（24 路会卡死 30 分钟以上），用 numpy 混（mix_sfx.py）。
10. 固定不变的只有：男声 MAI_03、纯白板、Caveat 手写体、右手正常肤色；其余设计每版可换。
